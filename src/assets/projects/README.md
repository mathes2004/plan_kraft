# Project photographs

Keep all existing and future project images in this folder, grouped by the supplied project number. For example, `331/external-wall-completed-finish.jpg` belongs to project 331.

The twelve published projects contain 32 original photographs. Copy future supplied images here before referencing them, preserve the original contents, and use descriptive filenames. Import them statically through `src/data/projects.ts`; never use a Windows Pictures path as an image URL.

Record the source filename, destination, dimensions and photo caption in `ASSETS.md`. Keep client identities, street addresses and personal contact details out of project descriptions. Preserve supplied project facts and describe only what each photograph shows.
